# اختبارات الواجهة المحلية

الصور تستخدم fixtures فقط؛ لا توجد اتصال أو كتابة إنتاج. كل دور داخل Browser مستقل، ومركز الحسابات يتحقق من #users.active والعنوان والفلاتر قبل التصوير.

نفّذ npm ci في جذر المشروع ثم npm install داخل qa-tools. يمكن تحديد CHROMIUM_EXECUTABLE_PATH لمسار Chromium المثبت محليًا. نفّذ ملفات *.mjs هنا كل ملف على حدة، مثل node qa-tools/closure-qa11_3.mjs. لا تجمع تشغيلها على نفس منفذ Vite.

الصور وJSON تذهب إلى qa-evidence/. لا تستخدم الصور كدليل لبيانات إنتاج حقيقية أو اتصال حي بمزود AI. closure يستخدم موفر محادثة تطويري وبيانات كتالوج المصدر؛ workspace يستخدم ردود أدوات/تأكيد fixtures ويعرض المكون الحقيقي.

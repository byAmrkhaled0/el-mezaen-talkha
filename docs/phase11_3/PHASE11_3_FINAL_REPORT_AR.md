# مزين مصر — Phase 11.3

تم البدء فقط من أرشيف Phase 11.2 النهائي، في مساحة مستقلة. لم يحدث Push أو Deploy أو تعديل بيانات إنتاج. النتيجة للمراجعة البصرية والوظيفية من المالك؛ لا تُعلن جاهزية الإنتاج.

## ما تغير

- مساعد واحد باسم «مساعدك الشخصي»، بعنوان فرعي «مساعد مزين للحجز والاستفسارات» وأيقونة روبوت. لا يُفتح FAQ عند تعطل المزود؛ الرد البديل يبقى داخل المحادثة نفسها.
- Backend حواري محدود بأربع استدعاءات أدوات، ثم رد عربي طبيعي. الأسعار والمواعيد والملكية والتأكيد تظل من الدوال الحالية. إنشاء الحجز/الإلغاء/التعديل لا تنفذ بواسطة النموذج.
- بطاقات خدمة بصورة وسعر ومدة، وبطاقات عمال بصور الكتالوج المشروعة أو شعار محايد، وأزرار مواعيد فعلية عند الاتصال بالخادم، وبطاقة تأكيد مرتبطة بـ draftId.
- كروت فرعين متوازنة: صورة أعلى التفاصيل، العنوان وساعات العمل والهاتف وأزرار اختيار/حجز. صورتان افتراضيتان مولدتان مختلفتان. صورة الإدارة تتقدم عليهما في جميع renderers.
- ثلاث صور افتراضية مختلفة للباقات، مع الاحتفاظ بأولوية الصور المخصصة وبخرائط الخدمات المتعددة الثابتة. الصور المولدة تسويقية تعبيرية، وليست إثباتًا لشكل الفروع الحقيقي.
- تشخيص ربط العامل بالفروع في الإدارة، وإجراء «تحديد فروع العامل»، وأدوات تدقيق/اقتراح merge فقط بدون اتصال أو كتابة Firebase.
- تطبيع /admin و/admin/ وباقي MPA routes في Vite dev وpreview. شاشة App Check محلية ذات هوية واضحة وخطوات تسجيل Debug Token؛ الحماية الإنتاجية لم تتغير.
- الرجوع وأعلى الصفحة عبر وحدة مشتركة. تواصل سريع في نهاية الصفحة بدل شريط تنقل ثانٍ دائم؛ السلة العائمة مخفية على الهاتف ويظهر عدادها في قسم التواصل.
- تصحيح تبعية source-map-js إلى الإصدار المصحح 1.2.2؛ npm audit الحالي = صفر في الواجهة وFunctions.

## حدود وإجراءات خارجية

1. لم يُختبر اتصال حي بمزود AI عبر مفتاح حقيقي. يلزم Secret الموجود AI_AGENT_API_KEY، وsettings/public.aiAgentEnabled=true. التفاصيل في AI audit؛ لم يُفعّل أي منهما إنتاجيًا.
2. يلزم تسجيل App Check debug token الخاص بجهاز المطور في Console إذا استخدم localhost مع Firebase الحقيقي. لا يوجد رمز محفوظ في المصدر أو الأرشيف.
3. جرد staff الإنتاجي لم يُقرأ عبر قناة مصرح بها في هذه المرحلة. جرد المصدر المحلي وحده لا يصلح لاعتماد ربط العمال؛ مطلوب export قراءة مصرح وmapping يعتمدها المالك عند وجود نقص.
4. GPS/Phone OTP/Google/FCM الفعلية على أجهزة وحسابات إنتاج لم تُنفذ؛ اختبارات emulator والعرض لا تستبدل اختبار الأجهزة بعد الموافقة.
